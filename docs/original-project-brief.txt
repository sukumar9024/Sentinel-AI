1. Project Objective
Build a centralized security observability platform that:
collects logs from applications, containers, hosts, and reverse proxies
normalizes events into a common schema
detects suspicious activity using rules and thresholds
correlates related alerts into incidents
enriches incidents with AI-assisted analysis
maps relevant activity to MITRE ATT&CK
stores security incidents
provides an analyst dashboard
sends alerts to Slack/Discord/email
exposes metrics about the security platform itself
supports secure production deployment on AWS
uses Terraform, Docker, CI/CD, secrets management, TLS, backups, monitoring, and RBAC
The system should work like a lightweight combination of:
SIEM
+
Security Analytics
+
Incident Management
+
AI-assisted SOC Analysis
